# Archie Coach

Connects VSCodium to Archie's Workshop on this PC. Archie sees which file and line you're on (only while the
eye in the status bar is on), and you can ask it to explain code, check a lesson step, or give a hint.
Right-click in the editor, or Ctrl+Alt+E (explain) and Ctrl+Alt+K (check). Everything stays on this PC.

What Archie's checkers find (the compiler, ruff for Python, node for JavaScript) shows up as squiggly lines in your
code and in the Problems panel, marked "Archie". In a course, Ctrl+Alt+K runs the exercise's tests.
